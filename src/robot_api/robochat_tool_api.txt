Robot Control Tool
==================

Use this tool to control the robot simulator. Each command below is available for use. Always specify parameters explicitly by name in the function call. For best results, provide all required parameters and review optional ones for your use case.

Commands:
---------

- move_robot: Move the robot base to specific coordinates in the environment.
  - Parameters: coordinates (list of [x, y, z])

- pickup_and_place: Pick up an object and place it at a given set of coordinates.
  - Parameters: object_name (str), target_location (list of [x, y, z]), arm (optional: 'left' or 'right')

- spawn_objects: Create a new object at specified coordinates in the simulation.
  - Parameters: object_choice (e.g. 'cereal', 'milk', 'spoon', 'bowl'), coordinates (list of [x, y, z]), color (optional)

- spawn_in_area: Create a new object on a named surface, with optional position offsets.
  - Parameters: object_choice (str), surface_name (str), offset_x (optional), offset_y (optional), color (optional), name (optional)

- get_placement_surfaces: List all available surfaces where objects can be placed.
  - Parameters: None

- pick_and_place_on_surface: Pick up an object and place it on a named surface, with optional offsets.
  - Parameters: object_name (str), surface_name (str), offset_x (optional), offset_y (optional), arm (optional)

- get_world_objects: Retrieve all objects in the world with optional filtering by type and area.
  - Parameters: exclude_types (optional: list), obj_type (optional: str), area (optional: str)

- list_robot_commands: List all available robot API commands and their descriptions.
  - Parameters: None

Best Practices:
---------------
- Always specify parameter names explicitly.
- Use lists for coordinates and locations, e.g., [1.0, 2.0, 0.5].
- Valid object choices: 'cereal', 'milk', 'spoon', 'bowl'.
- When using offsets, specify as separate offset_x and offset_y parameters.
- Valid arms: 'left', 'right'.
